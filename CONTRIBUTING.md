# Contributing to tfmodule-{tfmodule-name}

Thank you for your interest in this Terraform module for Azure Container Registry (ACR) with Azure Landing Zone compliance!

## Repository Status

This repository is **open for viewing and learning purposes**, but we have a specific contribution policy in place.

## How to Provide Feedback

We welcome feedback and suggestions! However, we only accept contributions in the form of **issues raised against this repository**.

### ✅ What we accept:
- Bug reports
- Feature requests  
- Documentation improvements suggestions
- Questions about usage
- Security vulnerability reports

### ❌ What we don't accept:
- Pull requests
- Direct code contributions
- Forks with proposed changes

## How to Submit Feedback

1. **Check existing issues** first to avoid duplicates
2. **Create a new issue** using the appropriate template (if available)
3. **Provide detailed information** including:
   - Clear description of the issue or suggestion
   - Steps to reproduce (for bugs)
   - Expected vs actual behavior
   - Terraform version and provider versions
   - Any relevant configuration snippets

## Issue Guidelines

When creating an issue, please:

- Use a clear and descriptive title
- Provide as much relevant information as possible
- Be respectful and constructive in your communication
- Follow any issue templates provided

## Security Issues

If you discover a security vulnerability, please create an issue with the "security" label or follow the guidelines in our SECURITY.md file.

## Questions?

If you have questions about this contribution policy or need clarification on how to submit feedback, please create an issue with your question.

Thank you for helping us improve this module through your valuable feedback!
